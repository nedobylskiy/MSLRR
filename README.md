<h1 align="center">Street Legal Racing Redline Multiplayer</h1>

Street Legal Racing Redline Multiplayer is a multiplayer modification based on the independent [SLRR_rev engine](https://github.com/nedobylskiy/SLRR_rev). It uses a clean, unmodified installation of **Street Legal Racing: Redline 2.2.1** as its base.
